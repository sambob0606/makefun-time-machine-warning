Write the funniest one-line warning label for a time machine, in 120 characters or fewer. The program holds several hand-written candidate labels, scores each against the judge's five published criteria (on-brief, hazard-as-joke, surprise at the end, straight-face official tone, economy), and writes the best one to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
